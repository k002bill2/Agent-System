핵심 설계 결정 Insights

  • 이중 에이전트 우주 — 런타임(src/backend/agents/)과 메타(.claude/agents/)가 한 리포에 공존하지만 실행 컨텍스트가 다릅니다. 같은 단어 "agent"의 의미가 두 가지라는 점이 신규 기여자가 가장 자주 헷갈리는 지점입니다.
  • HITL이 1급 노드 — 보통 미들웨어/인터럽트로 처리되는 HITL이 LangGraph 위 별도 waiting_node로 존재합니다. 덕분에 state checkpoint → 외부 승인 → resume 시나리오가 LangGraph의 native persistence와 자연스럽게 맞물립니다.
  • ExecutionStrategy = DAG planner — LeadOrchestrator의 SEQUENTIAL / PARALLEL / MIXED는 단순 옵션이 아니라 specialists에게 task_boundaries(do_not · wait_for · stop_if) 계약을 부여하며 격리 단위를 정의합니다.
  • shared-infra 공유는 정책 — Postgres/Redis/Qdrant를 image_maker · ppt-maker · livemetro와 공용하므로, 마이그레이션·백업은 다른 프로젝트와 협상이 필요한 결정입니다 (CLAUDE.md의 "down -v 금지").
  • 노드와 부수효과의 분리 — LangGraph 노드는 LLM 추론에만 집중하고, 모든 부수효과(DB/git/subprocess)는 services 계층에 위임됩니다. 이 덕분에 노드는 결정적 테스트가 가능합니다.
