<decisions_made>

- **squash 머지 안착 검증은 SHA 대조로**: `git branch --merged`/`git cherry` 대신 로컬 HEAD SHA == PR `headRefOid`
  + `state=MERGED`를 확인했다. squash는 새 커밋을 만들어 원본 SHA가 main 조상이 아니므로 도달성 기반 검사가
  false negative를 낸다. SHA 대조는 "미푸시 커밋 없음"까지 동시에 증명한다. 그래서 `-d`가 아닌 `-D`가 정당했다.
- **중간 CI `cancelled`는 정상, 최종 CI만 판정자**: 연속 머지 시 concurrency group이 이전 run을 취소한다.
  누적 lock 병합의 정합성은 최종 커밋 CI(`--locked` 잡)만이 증명한다.
- **#218은 rebase가 아니라 close**: main의 pyproject가 이미 `gitpython>=3.1.57`(#214 그룹이 올림)인데
  #218은 3.1.54 제안 → 머지하면 역행. `gh pr close`가 아닌 `@dependabot close`를 써야 봇이 처리됨으로 기록하고
  다음 주기에 같은 범프를 재생성하지 않는다.
- **#212는 rebase가 아니라 recreate**: js-yaml만 #217로 먼저 착지해 부분 중복 상태. rebase는 기존 의존성 집합을
